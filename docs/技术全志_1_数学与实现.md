## 第 A 篇 数学推导(全)

### A.1 假设(驱动全部 DGP 设计)
A1 一致性 `Y=Y(T)`;A2 正性 `P(T=t_k|U,X)≥c>0`;A3 潜在可忽略性 `Y(t)⟂T|(U,X)`;
A4 代理结构 `W⟂(T,V)|(U,X)` 且 `V⟂Y|(U,X,T)`;A5 逐臂完备性(两方向);A6 桥积分方程正则性。

### A.2 两个桥与识别定理 1(完整证明)

**桥方程**:
```
(B1)  E[ Y − h_k(W,X) | V,X,T=t_k ] = 0
(B2)  E[ 1{T=t_k} q_k(V,X) − 1 | W,X ] = 0
```
**伪结果**(STAR):`φ_k(O)=1{T=t_k} q_k(V,X)(Y−h_k(W,X)) + h_k(W,X)`。

**定理 1**:A1–A6 下,若 h_k 解 B1 **或** q_k 解 B2,则 `E[φ_k|X]=μ_k(X)`。

**证明**。记 `E[φ_k|X]=E[h_k(W,X)|X] + E[1{T=k}q_k(Y−h_k)|X]`。

*情形一:h 正确*。对内层求条件期望,先对 (V,X):
```
E[1{T=k}q_k(V,X)(Y−h_k) | V,X]
 = q_k(V,X)·E[1{T=k}(Y−h_k)|V,X]
 = q_k(V,X)·P(T=k|V,X)·E[Y−h_k|V,X,T=k]     （把 1{T=k} 拆成 P(T=k|V,X) 乘条件）
 = q_k(V,X)·P(T=k|V,X)·0 = 0                （B1）
```
故 `E[φ_k|X]=E[h_k(W,X)|X]`。而**结果桥识别**(POR,由完备性 A5)给 `E[h_k(W,X)|X]=E[Y(t_k)|X]=μ_k(X)`。∎

*情形二:q 正确*。
```
E[φ_k|X] = E[1{T=k}q_k Y|X] − E[1{T=k}q_k h_k|X] + E[h_k|X]
```
- **处理桥识别**(PIPW):`E[1{T=k}q_k(V,X) Y|X]=μ_k(X)`。
- 第二项对 (W,X) 求条件:`h_k(W,X)` 提出,`E[1{T=k}q_k(V,X)|W,X]=1`(B2),故
  `E[1{T=k}q_k h_k|X]=E[h_k(W,X)·1|X]=E[h_k|X]`,与 `+E[h_k|X]` 抵消。
- 剩 `μ_k(X)`。∎

**推论**:`τ_k(x)=E[φ_k−φ_0|X=x]`——把因果目标变成**伪结果差的条件期望**(可回归)。这是 Stage-2 的依据。

### A.3 定理 2(率双重稳健)——逐项展开

两桥都估计,记 `δ_h=ĥ_k−h_k`,`δ_q=q̂_k−q_k`。逐差:
```
φ_k(ĥ,q̂) − φ_k(h,q)
 = 1{T=k}[(q+δ_q)(Y−h−δ_h) − q(Y−h)] + δ_h
 = 1{T=k}[ q(Y−h) − q·δ_h + δ_q(Y−h) − δ_q·δ_h − q(Y−h) ] + δ_h
 = 1{T=k}[ −q·δ_h + δ_q(Y−h) − δ_q·δ_h ] + δ_h
```
取 `E[·|X]`,用真桥的 B1/B2:
- **h 一阶项**:`−E[1{T=k}q·δ_h|X]+E[δ_h|X]`。因 δ_h 是 (W,X) 的函数,
  `E[1{T=k}q(V,X)δ_h(W,X)|X]=E[δ_h·E(1{T=k}q|W,X)|X]=E[δ_h|X]`(B2 真 q),两者抵消 → **0**。
- **q 一阶项**:`E[1{T=k}δ_q(Y−h)|X]=E[δ_q·P(T=k|V,X)·E(Y−h|V,X,T=k)|X]=0`(B1 真 h)→ **0**。
- **剩**:`−E[1{T=k}·δ_q·δ_h|X]`。Cauchy–Schwarz:`|·|≤E[1{T=k}|δ_q||δ_h|]≤‖δ_q‖_{L2}‖δ_h‖_{L2}`。

**结论**:`|条件偏差| ≤ ‖ĥ−h‖·‖q̂−q‖`。两个一阶项消失 = **Neyman 正交**。三个直接后果:
(i) 单桥腐蚀不产生偏差(E2 DR 对照);(ii) 双桥腐蚀偏差 ~ `n^{−(a_h+a_q)}`(E2 乘积率);
(iii) 交叉拟合下桥误差进入二阶 → ATE/CATE 的 CI 覆盖率随 n 趋名义(E1、E10);
(iv) MV-OPM 的 **product 分数** `D_h·D_q` 正是想估计这个乘积余项。

### A.4 kernel-moment / MMR:从条件矩到无条件目标(RKHS 推导)

B1 是 `E[R|Z]=0`,`R=1{T=k}(Y−h_k)`,`Z=(V,X)`。等价:对丰富函数类 F,`E[R f(Z)]=0 ∀f∈F`。
取 F=RKHS `H`(核 k)的单位球,**最大矩限制(MMR)**:
```
J(h) = sup_{‖f‖_H≤1} ( E[R·f(Z)] )²
```
由**核均值嵌入**:`E[R·f(Z)]=⟨f, E[R·k(Z,·)]⟩_H`,故 `sup_{‖f‖≤1}⟨f,μ_R⟩²=‖μ_R‖²_H`,而
```
‖μ_R‖²_H = ⟨E[R k(Z,·)], E[R' k(Z',·)]⟩ = E_{(i,j)独立}[ R_i R_j k(Z_i,Z_j) ]
```
**→ sup 有闭式,无需对抗判别器**(Dikkala 2020;Kompa 2022 NMMR)。最小化 `J(h)` 把条件矩推向 0。

**U 统计量(无偏经验估计)**:目标是 `E_{i≠j}[R_i R_j k]`(独立两拷贝)。经验版必须**排除对角 i=j**才无偏:
对角项 `R_i²k(Z_i,Z_i)` 是 `E[R²k(Z,Z)]`(有偏成分)。恒等式:
```
Σ_{i≠j} R_i R_j K_ij = Rᵀ K R − Σ_i R_i² K_ii = Rᵀ(K − diagK)R
Ĵ = Rᵀ(K−diagK)R / (B(B−1))
```
高斯核 `K_ij=exp(−‖z_i−z_j‖²/(2·bw²))`。q 侧同理,`S=1{T=k}q_k−1`,工具 `u=(W,X)`。

**中位数启发式带宽**:`bw = median{‖z_i−z_j‖: i<j}`。理由:把核置于"成对相似度既非全 1 也非全 0"的
信息量最大尺度——MMD/核方法标准做法。大 n 时抽 ≤4000 对估中位(`opm/utils.py::median_bandwidth`)。

### A.5 sieve 桥的 2SLS(两侧完整代数)

**结果桥** `h_k(W,X)=Φ_h(W,X)ᵀβ_k`,工具基 `Ψ(V,X)`。B1 样本版(在 T=k 子样本)`E_n[(Y−Φ_hβ)Ψ]=0`。
sieve 最小距离/2SLS:先把回归子投影到工具张成的空间 `P_Ψ=Ψ(ΨᵀΨ)^{-1}Ψᵀ`,再解
```
β_k = (Φ_hᵀ P_Ψ Φ_h)^{-1} Φ_hᵀ P_Ψ Y
```
**处理桥** `q_k(V,X)=Φ_q(V,X)ᵀα_k`,工具 `ξ(W,X)`。B2:`E[(1{T=k}Φ_qᵀα−1)ξ]=0`,即线性系统
```
E[1{T=k} ξ Φ_qᵀ]·α_k = E[ξ]   →   A α = b,   最小二乘解 α=(AᵀA)^{-1}Aᵀb
```
两侧都加 ridge。**关键工程点**:多项式展开后**再标准化**(交叉项 x_i x_j 尺度差异极大,否则正规方程病态),
并 clip |·|≤8σ 驯服 U² 类重尾高阶特征。**特征数护栏**(见 B.9)防止高维爆炸。

### A.6 ATE 影响函数 CI

`ATE_k=E[φ_k−φ_0]`。该识别下 efficient influence function 就是中心化伪结果差 `ψ=φ_k−φ_0−ATE_k`,故
`√n(ATÊ_k−ATE_k)→N(0,Var(ψ))`。用样本方差估 `Var(ψ)`,`SE=sd(ψ)/√n`,`CI95=ATÊ±1.96·SE`。
交叉拟合 + Neyman 正交保证桥误差不进入一阶。

### A.7 dr_fallback:AIPW + Hájek 稳定化

无代理时 `h_k→m̂_k(X)`(逐臂结果回归),`q_k→1/π̂_k(X)`(softmax 倾向,π clip 到 [1/50,1]),代入 STAR
即经典 AIPW。插件倾向不满足 B2,故 `En[1{T=k}/π̂_k]` 未必=1。**Hájek 自归一化**:
```
q̃_k(X) = (1/π̂_k(X)) / En_train[1{T=k}/π̂_k]   →   En_train[1{T=k}q̃_k]=1
```

### A.8 CATE 逐点推断(E10):局部线性 + 三明治方差(完整推导)

由定理 1,OOF 伪结果差 `D_i=φ_1−φ_0` 满足 `E[D_i|X_i]=τ(X_i)`,即 `D_i=τ(X_i)+噪声`。对一维修饰变量
`m=x_j` 做**核加权局部线性**:权重 `w_i=exp(−½((m_i−x0)/bw)²)`,设计 `Z_i=[1, m_i−x0]`,
```
β̂=argmin Σ w_i(D_i−Z_iᵀβ)²=(ZᵀWZ)^{-1}ZᵀWD,   τ̂(x0)=β̂_0（截距）
```
**为何局部线性(而非局部常数)**:对线性 τ 无偏、无边界偏差 → 任意带宽近似无偏,带宽只影响方差,可放大以收紧 CI。
**异方差稳健三明治方差**(把核权重视为固定):残差 `r_i=D_i−Z_iᵀβ̂`,
```
Var(β̂)=A^{-1}(Σ_i w_i² r_i² Z_i Z_iᵀ)A^{-1},  A=ZᵀWZ,  SE=√Var(β̂)[0,0]
```
**为何覆盖率随 n 趋名义**:CI 只捕伪结果采样方差,不含桥估计方差;但由 Neyman 正交(定理 2)桥误差是**二阶**,
随 n 更快消失,故小 n 轻微欠覆盖、n→∞ 趋 95%。**子组 ATE**(更稳):分位分箱,箱内 `mean(D)±1.96 sd/√n_bin`
——普通样本均值 CI,SE 略保守(含箱内 τ 变差),覆盖 ≥ 名义。

### A.9 生成器(E7):DDPM 前向/反向/蒸馏

余弦调度 `ᾱ_t`。前向 `q(y_t|y_0)=N(√ᾱ_t y_0,(1−ᾱ_t))`。ε-预测损失 `‖ε−ε_θ(y_t,t,c)‖²`,
条件 `c=concat(MLP_embed(X),arm_emb,sin_emb(t),y_t)`。**祖先采样**(DDPM 后验 `q(y_{t-1}|y_t,ŷ_0)`):
```
ŷ_0=(y_t−√(1−ᾱ_t)ε_θ)/√ᾱ_t
μ=√ᾱ_{t-1}·β_t/(1−ᾱ_t)·ŷ_0 + √α_t·(1−ᾱ_{t-1})/(1−ᾱ_t)·y_t,  α_t=ᾱ_t/ᾱ_{t-1}, β_t=1−α_t
y_{t-1}=μ+√β_t·z  （t>0;t=0 取 ŷ_0）
```
**DDIM 确定性**(可微,蒸馏梯度用):`y_{t-1}=√ᾱ_{t-1}ŷ_0+√(1−ᾱ_{t-1})ε_θ`。**蒸馏损失**(Stage1-2 冻结):
`L_distill=mean_k MSE(mean_M DDIM_sample(X,k), μ̂_k)`;总 `L=L_ddpm+λ_distill·L_distill`(唯一可调超参)。
**已知局限**:蒸馏只去偏均值,高阶矩继承事实条件形状。

### A.10 精确桥 DGP 的线性方程(MV-OPM §4;取代 E2 债务)

有限离散 `U∈{0..dU-1}`(先验 π);`W|U~Cat(B_W[u,:])`、`V|U~Cat(B_V[u,:])`(满秩,W⟂V|U);
`T|U~Bernoulli(e_u)`(X-free,含混杂);`X~N(0,I_p)⟂U`;`Y=τ(X)T+c_U f_U[U]+β'X+N(0,σ²)`,`τ(X)=2+X_1`。

**结果桥**:令 `Ỹ=c_U f_U[U]`(E[Ỹ|U=u]=c_U f_U[u])。解 `E[Ỹ−h̃_t(W)|V=v,T=t]=0 ∀v`。用 Bayes
`P(U=u|V=v,T=t) ∝ π_u B_V[u,v] Pt[u,t]`,W⟂V,T|U 给 `P(W=w|V=v,T=t)=Σ_u B_W[u,w]P(U=u|V=v,T=t)`,得线性系统
```
M_t h̃_t = r_t,  M_t[v,w]=Σ_u B_W[u,w] P(U=u|V=v,T=t),  r_t[v]=Σ_u P(U=u|V=v,T=t)·c_U f_U[u]
```
完整桥 `h_t(W,X)=τ(X)t+β'X+h̃_t[W]`。**处理桥**:解 `E[1{T=t}q_t(V)|W=w]=1 ∀w`,用 `P(V=v,T=t|W=w)=
Σ_u B_V[u,v]Pt[u,t]P(U=u|W=w)`,`P(U=u|W=w)∝π_u B_W[u,w]`,得 `N_t q_t=1`,`N_t[w,v]=Σ_u B_V[u,v]Pt[u,t]P(U=u|W=w)`。
**数值验证**(n=2e5):B1 max|resid|≈0.007-0.015,B2∈[0.994,1.007],STAR-ATE=2.01。→ 有了**真 q_true**。

### A.11 MV-OPM 的分数动机与"方差盲点"分析

**动机**:定理 2 说因果偏差 `~‖δ_h‖·‖δ_q‖`。留出矩违背 `D_h,D_q` 是 `‖δ_h‖,‖δ_q‖` 的观测代理,故
**product `D_h·D_q` 应估计因果偏差**。分数(低=好,`opm/validation/selector.py`):
```
product = log(D_h+ε)+log(D_q+ε)   （主）;  h_only=D_h; q_only=D_q; sum=z(D_h)+z(D_q); max=max(z(D_h),z(D_q))
```
**方差盲点(失败根因,理论解释)**:识别矩测的是**偏差**(`E[R|Z]=0`),且残差按 `sd(R)` 归一化 →
`D` 只反映"归一化残差与工具的相关",**与残差方差无关**。而 CATE 误差 = 偏差² + 方差。一个过灵活、低偏差-高方差
的候选(高阶 sieve)满足留出矩(`D` 低)却有灾难 CATE 方差。**修正方向(探索性)**:CATE 误差 ≈ 偏差 + 方差,
矩测偏差,伪结果方差/ATE-CI 宽度测方差,`biasvar=log(D_h)+log(D_q)+log(po_var)` 兼顾两者。

## 第 B 篇 实现细节(全,含张量形状与设计理由)

### B.1 桥训练 `opm/bridges/kernel_moment.py`(核心循环)
`KernelBridges.fit(ds)` 流程:
1. 特征/工具:h 的网络输入 `feat_h=(W,X)`、核工具 `inst_h=(V,X)`;q 反之。各自 `standardize_fit` 在**当前训练折**。
2. 带宽:`bw_h=median_bandwidth(inst_h)`、`bw_q=...`。RFF 早停 bank `omega~N(0,1/bw²)`。
3. 网 `net_h,net_q=TrunkNet(feat_dim,K,arm_emb=8,hidden=128,depth=3)`;`EMA(0.99)`;`AdamW(lr1e-3,wd1e-4)`。
4. 训练折/验证折 8:2 划分。每 epoch,批 `bs=min(512,len)`,整批 B×B 核矩阵 `Kh,Kq`;**逐臂累加**损失:
   ```python
   for k in range(K):
       mask=(Tb==k).float(); hk=net_h(fh[bt],arm=k); R=mask*(Yb-hk); loss+=ustat_quadratic(R,Kh)
       gk=net_q(fq[bt],arm=k); qk=clip(1+softplus(gk),max=50); S=mask*qk-1; loss+=ustat_quadratic(S,Kq)
   ```
   总损失=Σ_k(L_h^k+L_q^k)。**h 网与 q 网参数不相交**,合并 backward 等价于分别训练(非跨阶段联合)。
5. 每 `eval_every` epoch 在验证折算 RFF 残差诊断 `_val_residual`(`max_j|En[R g_j]|/sd(R)`,h/q 取平均),
   保留分数最低的 EMA 权重(patience 30);用 EMA 影子权重做所有下游预测。
6. `predict_h(W,X)→(n,K)`、`predict_q(V,X)→(n,K)`(对**所有臂**;h_k 对所有样本有定义,不只 T=k)。

**默认超参**(`BridgeConfig`):lr 1e-3,wd 1e-4,max_epochs 300,patience 30,batch 512,hidden 128,depth 3,
arm_emb 8,ema 0.99,q_max 50,n_rff 100,val_frac 0.2,eval_every 2。实验按 config 覆盖(卷二给具体值)。

### B.7 sieve `opm/bridges/sieve.py`
`_Basis`:`scaler_in`→`PolynomialFeatures(degree,include_bias=False)`→`scaler_out`→`clip(-8,8)`→加偏置列。
`_twosls(Phi,Psi,y)`:`Pinv=solve(ΨᵀΨ+ridge,Ψᵀ)`;`Phi_hat=Ψ@(Pinv@Φ)`;`β=solve(Φ_hatᵀΦ+ridge, Φ_hatᵀy)`。
`_q_solve(PhiQ,Xi,idx)`:`A=(Xi*1{T=k})ᵀPhiQ/n`;`b=Xi.mean(0)`;`α=solve(AᵀA+ridge, Aᵀb)`。

### B.8 dr_fallback `opm/bridges/plugin.py`
`linear=True`→`Ridge(α=1)`+`LogisticRegression`;否则 `HistGradientBoosting{Reg,Clf}`。`_raw_q`:
`1/clip(π,1/50,1)`;`norm_k=En_train[1{T=k}q_raw]`;`predict_q=clip(raw_q/norm_k,0,q_max)`(Hájek)。

### B.9 【MV-OPM】候选库 `opm/candidates/library.py`
`CANDIDATE_SPECS`:name→(h_solver,q_solver);6 个候选,`CANDIDATE_NAMES=sorted(...)`(固定序)。
`CandidateSet.fit(view)`:`needed=sorted{唯一 solver}`,**每唯一 solver 只拟合一次**;候选是缓存 solver 的组合
`_FittedCandidate(h_solver,q_solver)`,`predict_h/q` 转发。
**确定性修复**(测试捕获):kernel 网初始化用 torch 全局 RNG → 同进程顺序拟合不可复现。修:
```python
ssd=self.seed+17*si+1; torch.manual_seed(ssd); np.random.seed(ssd)   # 隔离全局 RNG
```
**特征护栏**(修 segfault):`_Basis.fit` 若 `comb(n_in+deg,deg)>6000` 抛 ValueError(可捕获),不再让 67 维×deg3
(≈57000 特征)撑爆 BLAS。

### B.10 【MV-OPM】矩验证器 `opm/validation/moments.py`
`build_bank(inst_h,inst_q,n_rff=200,seed=20240)`:**候选无关的固定种子**;`standardize_fit`+`median_bandwidth` 仅用
**留出集工具**;`omega~N(0,1/bw²)`,`b~U(0,2π)`。`discrepancy_from_hq(bank,h,q,view,kinds)`:逐臂
`R=1{T=k}(Y−h_k)`,`S=1{T=k}q_k−1`,**按臂内 sd 归一化** `Rn=R/(sd(R)+ε)`;RFF `g=cos(z_std@omᵀ+b)`;
`D_h_rff_l2=sqrt(mean_j(En[Rn·g])²)`(臂上取平均);另有 rff_max、mmr(U 统计量)。**同一 bank 用于全候选**(测试断言)。

### B.11 【MV-OPM】选择器 `opm/validation/selector.py`
`compute_scores(cand_D,kind)`→{score:{cand:val}};`select=argmin`。见 A.11。**不 import oracle**(测试断言)。

### B.12 【MV-OPM】嵌套交叉拟合 `opm/estimator/nested_crossfit.py`
`nested_mvopm(view,cfg)`:外折 `make_folds(n,outer_folds)`。每外折:`outer_train=all∖outer_test`;
内折 `make_folds(len(outer_train),inner_folds)`,**局部索引→全局** `inner_valid=outer_train[inv_local]`;
每候选在 `inner_train` 拟合、在 `inner_valid` 算 D(bank 仅由 inner_valid 建)→ 内折平均 → `select` →
选中者在**全 outer_train** 重拟合、预测 `outer_test` → `compute_phi` 填 OOF;全外折后 `fit_cate_and_ate`。
**索引审计**(每折记布尔):`inner_train∩inner_valid=∅`、`inner⊂outer_train`、`outer_test∉inner`、`outer_train∩outer_test=∅`。

### B.14 【MV-OPM】评估编排 `opm/experiments/mvopm/core.py`(**允许**读 oracle,选择器不读)
